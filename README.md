# 赛格斯 SEGUS · 手机端（Android）

> 桌面那个助理的随身入口。手机上说话，活还是电脑干。

---

## 它是什么

赛格斯桌面端跑在你自己的电脑上，拥有文件、表格、浏览器、工具的真实能力。
这个仓库分发的是**手机端 App**：它把手机变成桌面助理的另一张嘴和另一双手。

- **语音直连**：说话即可下达任务，回复也能直接念出来
- **任务同步**：手机上发起的任务在电脑上执行，进度与结果实时回到手机
- **文件互传**：手机上的图片、文档可直接丢给助理处理；桌面交付的文件也能拉回手机
- **同一份记忆**：手机上说过的事，电脑那边记得住；反过来也一样
- **不额外上云**：模型推理、记忆、文件都在你的电脑上，手机只是遥控与前端

## 安装

前往 [Releases](https://github.com/zhou99999999/SEGUS-Mobile/releases/latest) 下载最新版：

| 文件 | 说明 |
|---|---|
| `SEGUS-Mobile-0.1.42-universal-release.apk` | 通用安装包（推荐，适配所有机型） |
| `SEGUS-Mobile-0.1.42-arm64-v8a-release.apk` | 仅 arm64（体积更小，绝大多数手机适用） |

安装时系统会提示「未知来源」，允许后即可安装。覆盖安装会自动保留原有数据。

## 配对步骤

1. 手机与电脑连同一个 Wi-Fi；
2. 在电脑上打开赛格斯桌面端，进入「手机连接」，页面会显示地址与配对码；
3. 手机端首次启动，按引导填入地址与配对码；
4. 连上后即可用语音或文字对话，与电脑端共享同一个助理、同一份记忆。

## 系统要求

- Android 8.0（API 26）及以上
- 与运行赛格斯桌面端的电脑处于同一局域网（异地使用需自行做内网穿透）

## 隐私

- 手机端不在云端保存对话；数据跟随你的电脑端数据目录
- 麦克风、相机、相册权限只在对应功能被触发时使用
